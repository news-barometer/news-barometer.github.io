# Барометр войны

Открытый монитор: к какому исходу идёт война России и Украины. Четыре сценария до конца 2027 года (заморозка без соглашения, заморозка по соглашению, продолжение войны, мирный договор), 27 наблюдаемых индикаторов, обновление по понедельникам.

Страница: https://news-barometer.github.io/ — `index.html`, одна статическая страница без зависимостей (кроме Google Fonts), публикуется через GitHub Pages.

## Обновление оценки

В `index.html` меняется только блок `const SEED = {...}` (date, vals, notes, запись в hist).

- `scripts/apply_seed.py seed.json` — применяет новую оценку из JSON (`{"date","vals","notes"}`), проверяя, что каждая замена нашлась ровно один раз, и добавляет запись в историю.
- `node scripts/score.js [index.html] [vals]` — считает показание по формуле страницы: доли сценариев, стрелка, флаг НАТО.

Отметки: 0 — нет, 1 — частично, 2 — да. Заметка к каждому индикатору («Основание») — факты с датами и источниками, без оценочных слов.
