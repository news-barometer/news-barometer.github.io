# Барометр войны

Открытый монитор: к какому исходу идёт война России и Украины. Четыре сценария до 2028 года (заморозка без соглашения, заморозка по соглашению, долгая война, мирный договор), 23 наблюдаемых индикатора, обновление по понедельникам.

Страница: `index.html` (одна статическая страница, без зависимостей кроме Google Fonts). Публикуется через GitHub Pages.
